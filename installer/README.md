# 网页安装向导

把「装一套云盘」压缩成「填几个空」：环境自检 → 填写配置 → 自动部署 → 完成。
不需要懂 `systemd`、不需要手写 nginx 反代、不需要记 `init.sql` 在哪。

## 怎么启动

两种方式，任选一种（**需要 root**）：

```bash
# 方式一（推荐）：让安装器先把 JDK / MySQL / nginx 装好，再拉起向导
sudo bash install.sh --web

# 方式二：环境已经就绪，只想起向导页面
sudo python3 installer/web-install.py --repo .
```

启动后终端会打印一条带访问口令的网址，例如：

```
      http://你的服务器IP:8099/?t=1a2b3c4d5e6f7a8b
```

**口令只显示一次**，用它打开页面才能操作；装完之后向导进程会自动退出。

## 向导做了什么

1. **环境自检**：Python / JDK 21 / MySQL / nginx / Node / 磁盘空间 / 是否已装过一次，逐项给结论
2. **填写配置**：站点域名与名称、管理员账号密码、数据库名与密码、后端端口、单文件上限，密码旁边有「随机」按钮
3. **自动部署**：本质上是把这个界面的选择拼成一条命令，交给 [`../install.sh`](../install.sh) 执行，全过程日志实时显示在网页上
4. **完成**：从 `/etc/jdy-cloud/install-result.json` 读出首页地址、后台地址、管理员账号密码、站点目录、配置文件路径，一键复制

## 常用参数

| 参数 | 作用 |
| :--- | :--- |
| `--repo <目录>` | 源码目录，默认当前目录；目录下必须有 `backend/pom.xml` |
| `--installer <文件>` | 指定安装脚本，默认用源码根目录的 `install.sh` |
| `--port <端口>` | 向导自己的监听端口，默认 `8099` |
| `--loopback` | 只监听 `127.0.0.1`，配合 nginx 反代更安全（此时不设访问口令） |
| `--token <口令>` | 自定义访问口令；不指定时非本机监听会随机生成 |
| `--bt` | 宝塔面板模式 |
| `--bt-java` | 宝塔「Java 项目管理器」托管模式（隐含 `--bt`） |
| `--skip-frontend` | 只装后端，不部署前端 |
| `--use-prebuild` | 用编译好的前端，不在服务器上装 Node 编译 |

## 宝塔用户看这里

宝塔面板会被自动识别（检测到 `/www/server/panel` 即切换目录结构）：

- 站点目录变成 `/www/wwwroot/<域名>`，后端目录变成 `/www/wwwroot/jdy-cloud`
- nginx 站点配置写进 `/www/server/panel/vhost/nginx/<域名>.conf`，可以在面板里继续改
- 用面板「Java 项目管理器」托管时加 `--bt-java`：向导不写 systemd，而是生成
  `start.env` + `bt-start.sh`，并在完成页把**项目类型 / 项目路径 / 项目名称 / 项目 JDK /
  启动命令 / 端口**逐项列出来，照抄到面板里点「启动」即可

手动部署的逐字段说明见 [../宝塔面板部署教程.md](../宝塔面板部署教程.md)。

## 常见问题

| 现象 | 原因与处理 |
| :--- | :--- |
| 打不开 8099 端口 | 安全组 / 防火墙放行 8099；或改用 `--loopback` 让 nginx 反代 |
| 提示口令不正确 | 用终端打印的那条完整网址（带 `?t=`）；换端口重启会重新生成口令 |
| 卡在「环境自检」 | 自检只是提示，不阻塞安装；确认服务器能连外网即可继续 |
| 安装中断 | 网页上会显示退出码和最后几行日志；修好问题后刷新页面重试 |
| 装完后向导还在跑 | 点完成页的「关闭向导」，或终端按 `Ctrl+C`；站点不受影响 |

> Python 3 标准库就够，不需要 `pip install` 任何东西。
